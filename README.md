Task Tracker

A simple, responsive daily task management application that allows users to add, complete, delete, and filter their daily tasks. Tasks are saved in the browser using Local Storage, so they remain available even after the browser is closed or refreshed.

Project Overview

Task Tracker is a beginner-friendly JavaScript project designed to help users organise their daily activities and monitor their productivity.

The application provides a clean and intuitive interface for managing everyday tasks without requiring user registration or a backend database.

Features

Add Tasks: Create and add new daily tasks.

Complete Tasks: Mark tasks as completed.

Delete Tasks: Remove tasks that are no longer needed.

Filter Tasks: View all, pending, or completed tasks.

Persistent Storage: Save tasks using browser Local Storage.

Responsive Design: Work across desktop, tablet, and mobile devices.

Technologies Used

HTML5 – Application structure.

CSS3 – Styling and responsive layout.

JavaScript (Vanilla JS) – Application functionality and interactions.

Local Storage – Saving tasks within the browser.

Getting Started

1. Clone the Repository

git clone <repository-url>

2. Navigate into the Project Folder

cd task-tracker

3. Open the Project

Open index.html in your browser or use the Live Server extension in Visual Studio Code.

How It Works

Enter a task in the input field.

Click the Add Task button.

Mark a task as completed when finished.

Use the filter options to organise your task list.

Delete tasks when they are no longer needed.

Your tasks are automatically saved in the browser's Local Storage.

Future Improvements

Add task due dates.

Add task priority levels.

Display the total number of tasks.

Add search functionality.

Add dark mode.

Introduce task categories.

Learning Objectives

This project helps develop practical skills in:

DOM manipulation.

JavaScript event listeners.

Arrays and objects.

Array methods such as filter() and map().

Browser Local Storage.

Responsive web design.

CRUD operations (Create, Read, Update, Delete).
